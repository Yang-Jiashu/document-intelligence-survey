# Beyond OCR manuscript

This directory builds the visual, mechanism-led technical report of **Beyond OCR: A Survey of Document Intelligence from Structured Perception to Multimodal Question Answering**.

## Edit the shared sources

- Edit the literature chapters in `../sections/`: `layout.tex`, `ocr.tex`, `table.tex`, `text.tex`, `multi.tex`, and `eval.tex`.
- Edit the abstract, introduction, and conclusion in `sec/0_abstract.tex`, `sec/1_intro.tex`, and `sec/7_conclusion.tex`.
- Edit title, author information, links and PDF metadata in `main.tex`.
- Keep `main.bib` and `../custom.bib` consistent when changing bibliography metadata.
- The remaining `sec/` files and the body of `../acl_latex.tex` are generated by `../scripts/sync_paper_sources.py`. Update their shared sources, then rerun the helper.

The main manuscript retains the full literature discussions across layout, OCR, table understanding, document RAG, vision-language systems and evaluation. Mechanism comparisons and worked diagrams accompany that coverage. The historical copy in ../supplementary/literature/ continues to supply the 410-paper website index through scripts/build_paper_index.py; it does not replace the restored main chapters. The ACL wrapper uses the same main body and abstract with format-specific packaging.

## Build

From the repository root:

```bash
bash scripts/build_paper.sh
```

The default result is `.build/paper/main.pdf`. An absolute output directory can be passed as the first argument. The helper synchronizes the sources, compiles the report with pdfLaTeX/BibTeX, and checks for unresolved citations and references. It uses only checkout-local caches when an installed minimal TeX distribution is missing formats or maps. A normal full TeX Live installation needs no such initialization.

For source synchronization only:

```bash
python scripts/sync_paper_sources.py
```

For the alternative ACL format, compile `acl_latex.tex` with XeLaTeX and BibTeX using the packages and fonts in its preamble. The report PDF is the validated download supplied for this revision.

## Rebuild corrected vector figures

With Python and ReportLab installed, run from the repository root:

```bash
python scripts/figures/build_evidence_diagrams.py
python scripts/figures/build_document_timeline.py
python scripts/figures/build_document_case.py
python scripts/figures/build_evaluation_cases.py
```

The compatibility entry point build_evidence_diagrams.py delegates to build_visual_foundations.py and build_visual_retrieval.py. The former text-card diagrams and unused taxonomy/date matrices are no longer included in the main manuscript.

The scripts write matching figure PDFs to both `figs/` and `../figs_by_qixingyu/`. Timeline dates mean the first public release year documented by the embedded source metadata; a citation's later venue year may differ.

The main document-AI chronology shows 32 selected milestones on one S-shaped timeline. A two-page complete companion atlas retains all 62 selected works and evaluation resources from 2007 through 2026, split into 31 perception/model foundations and 31 reasoning/evidence-access entries. Both use `../scripts/figures/document_timeline_sources.json` as the factual source; the main selection is explicit in the generator. Model labels are 17.5pt and retained brand icons 19pt in native 1100×500 figures. Placeholder icons and within-group repeated brand icons are omitted. The generator exports both the main figure and `../docs/chronology-atlas.pdf`, linked from the paper. A pale yellow highlight means that public trained weights were verified on the recorded inspection date, not that the model was released on the paper date or shares a common license. Figures 13 and 14 use constructed financial and staffing reports to explain cross-page evidence and evaluation errors; they are not experimental results.
