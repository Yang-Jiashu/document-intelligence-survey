Abstract

Document intelligence encompasses reading a page, classifying its purpose, extracting records, and using documents to retrieve information, answer questions, or generate new text. These tasks place different demands on the same source. A category label can route an invoice to the right workflow even if the total is unreadable; extracting the total requires linking a value to its field and unit. This survey follows such distinctions through OCR and layout analysis, table understanding, retrieval, vision-language models, and document applications.

We compare the input representation, context supplied, evidence granularity, inference procedure, and evaluation target of representative approaches. Examples from forms, receipts, financial reports, and multi-document summaries show where text, coordinates, images, and executable programs preserve different information. Within-study comparisons on FUNSD and FinQA illustrate how access to image features or gold evidence changes the interpretation of a reported score. A cross-tabulation of evidence type and reference program length in the FinQA test set connects one worked example to the prevalence of related cases. We distinguish recognition and extraction quality, retrieval relevance, generation fidelity, and evidence support so that each task can be assessed on its own terms.
